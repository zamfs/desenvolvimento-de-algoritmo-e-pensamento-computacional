# Calculadora no Flowgorithm

## Informações da atividade

- **Disciplina:** Desenvolvimento de Algoritmo e Pensamento Computacional
- **Instituição:** UDF
- **Aluno:** Zamorano Fragoso de Sousa


## Objetivo

Desenvolver uma calculadora utilizando o **Flowgorithm**, aplicando conceitos fundamentais de lógica de programação, como entrada e saída de dados, variáveis, operadores e estruturas condicionais.

O programa foi desenvolvido para reunir **20 operações diferentes de cálculo**, disponibilizadas por meio de um menu principal. Entre as operações estão as funções obrigatórias de **cálculo do IMC** e **cálculo de áreas de figuras geométricas**.

## Funcionamento

Ao iniciar o programa, o usuário visualiza um menu com 8 categorias de cálculo:

1. Calculadora de área;
2. Cálculo de IMC;
3. Calculadora simples;
4. Conversor de temperatura;
5. Identificação de número par ou ímpar;
6. Cálculo de desconto;
7. Comparador de valores;
8. Conversor de unidades.

Após escolher uma categoria, o programa solicita os dados necessários, realiza o processamento correspondente e apresenta o resultado na tela.

## 20 operações implementadas

Embora algumas operações estejam agrupadas em categorias, o projeto totaliza **20 operações de cálculo**, conforme a contagem abaixo.

### 1. Cálculo de IMC — 1 operação

- Cálculo do **Índice de Massa Corporal (IMC)**, incluindo a classificação do resultado.

### 2. Cálculo de área — 4 operações

- Área de quadrilátero;
- Área de triângulo;
- Área de círculo;
- Área de losango.

### 3. Calculadora básica — 5 operações

- Soma;
- Subtração;
- Multiplicação;
- Divisão;
- Potenciação.

### 4. Conversão de temperatura — 2 operações

- Celsius para Fahrenheit;
- Celsius para Kelvin.

### 5. Par ou ímpar — 1 operação

- Identificação de um número como **par ou ímpar**.

### 6. Desconto — 1 operação

- Cálculo do valor final de um produto após a aplicação de uma porcentagem de desconto.

### 7. Comparação de valores — 1 operação

- Comparação entre dois valores, identificando se o primeiro é maior, menor ou igual ao segundo.

### 8. Conversão de unidades — 5 operações

Conversão de valores em metros para:

- Milímetros (mm);
- Centímetros (cm);
- Decímetros (dm);
- Hectômetros (hm);
- Quilômetros (km).

### Total

**1 + 4 + 5 + 2 + 1 + 1 + 1 + 5 = 20 operações**

## Funções obrigatórias

O projeto atende às duas funções obrigatórias propostas na atividade:

- **IMC:** cálculo do Índice de Massa Corporal e classificação do resultado;
- **Área:** cálculo da área de quatro figuras geométricas — quadrilátero, triângulo, círculo e losango.

## Conceitos de lógica de programação utilizados

Durante o desenvolvimento foram utilizados:

- Variáveis inteiras, reais e do tipo texto;
- Entrada de dados pelo usuário;
- Saída de informações e resultados;
- Operadores aritméticos;
- Operadores relacionais;
- Operador de resto da divisão (`%`);
- Estruturas condicionais (`if/else`);
- Cálculos matemáticos;
- Comparação de valores;
- Conversão de unidades;
- Organização das operações por meio de um menu.

## Como executar

1. Tenha o **Flowgorithm** instalado em seu computador.
2. Baixe ou clone este repositório.
3. Abra o arquivo `calculadora.fprg` no Flowgorithm.
4. Execute o fluxograma pelo botão de execução.
5. Escolha uma das opções apresentadas no menu.
6. Informe os valores solicitados.
7. Confira o resultado apresentado pelo programa.
